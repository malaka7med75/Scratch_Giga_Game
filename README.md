# 🎮 Giga & The Magic Crystals — Scratch Game

An interactive 2D arcade game built with **Scratch**, featuring player movement mechanics, dynamic score tracking, and automated enemy tracking.

---

## 🌟 Game Overview

In this game, the player controls **Giga** to collect magical crystals while avoiding the hunting **Owl**. As the player's score increases, the crystal transforms, granting double points and triggering new sound effects!

---

## 🕹️ Controls & Gameplay

* **Up Arrow** (`↑`) — Move Up
* **Down Arrow** (`↓`) — Move Down
* **Left Arrow** (`←`) — Move Left
* **Right Arrow** (`→`) — Move Right

### 🎯 Objective:
Collect as many crystals as possible to build your score while dodging the Owl chasing you from above.

---

## ✨ Features & Mechanics

* **Dynamic Scoring System**: 
  * **Score < 5**: Collect standard crystals for **+1 point** (Triggers `Collect` sound).
  * **Score ≥ 5**: Crystals evolve into **Crystal-b**, awarding **+2 points** (Triggers `Magic Spell` sound).
* **AI Enemy Pursuit**: The **Owl** continually tracks and glides toward Giga's location.
* **Game Over System**: Colliding with the Owl triggers a `Lose` sound effect and stops the game.

---

## 🛠️ Project Structure & Assets

This project repository includes the core JSON project file along with all original audio and visual assets:

* **`project.json`**: The main Scratch logic and block configurations.
* **Audio Assets (`.wav`)**: Sound effects including `Collect`, `Magic Spell`, and `Lose`.
* **Vector Graphics (`.svg` & `.png`)**: Visual sprites for Giga, Owl, Crystal variations, and backgrounds.

---

## 🚀 How to Run the Game

1. Download the **`game.sb3`** file from this repository.
2. Open the official [Scratch Online Editor](https://scratch.mit.edu/projects/editor/).
3. Click on **File** > **Load from your computer**.
4. Select the downloaded `.sb3` file and click the **Green Flag** to play!
